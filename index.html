Discrete-event timeline & rule trace

TimeEventStageBusiness rule / effect

This is a simulated event log, not records from a real workplace. Showing the most recent events up to the selected time.

Four FIFO workstations in series. Arrivals come in fixed-size batches at exponentially distributed intervals; the specified arrival rate is an expected orders/hour, not a guaranteed count. Individual service times equal 60 ÷ station capacity (minutes) multiplied by a bounded triangular variation factor. Each staffed workstation has independent parallel workers. A reproducible per-order test may trigger one downtime period before service at a station; no work is processed during repair.

Orders cannot skip stages, queues have unlimited buffer space, and transfer time is zero. Once started, service is non-preemptive. There is no rework, scrap, priority dispatch, shift break, setup delay, inventory constraint or physical travel limit. Batches determine arrival clustering, not processing lot size. The simulated day is 480 minutes; unfinished orders remain WIP.

Capacity = minimum of nominal worker rate × workers across the four stations. This is a steady-state planning benchmark, not a strict finite-window bound under variable service times. Realized throughput = actually completed orders ÷ elapsed time. Busy utilization includes true processing minutes only; worker downtime is excluded from the busy numerator. Waiting and lead time use only orders completed at the selected time. Random service variation and limited warm-up make small-sample outcomes noisy. These outputs are synthetic demonstrations, not operational forecasts.

Use “Run conservation tests” to inspect automated invariants and edge cases.
Educational, fully local model. This browser file performs no network requests and stores no user credentials. Dragging workers changes staffing in the simulation; it does not change a real facility. A fixed random seed is supplied for repeatability, and no performance figures should be interpreted as measurements from a real operation.
